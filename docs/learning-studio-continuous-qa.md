## 구현 결과

1. 기존 문장 타임라인의 길이를 합산하는 순수 `lessonClock` 추가. 강 전체 탐색, 챕터 눈금/제목, 장면을 넘는 되감기와 상태 복원, 강 시간 기준 이어 보기 및 해시 진입 지원.
2. 일반 장면은 자동 연결. 퀴즈·슬라이더는 설명 끝에 정지하고 정답 제출 또는 계속 버튼으로 재개. 장면 전환 240ms 동안 지시를 숨기고 이전 무대 120ms 페이드아웃 → 새 무대 120ms 페이드인.
3. 상단 강 제목 아래 현재 위치/목차. 모바일 바텀시트, 집중 모드 목차, Esc·바깥 클릭·항목 선택 닫기 및 접근성 속성 적용.
4. aside의 장면 목록 제거. 시간 비율 진행률, 전체 교육과정, 완료 표시, 준비 중 비활성, 단원 펼침 저장, 현재 단원 자동 펼침, 마지막 강 이어 보기 제공.
5. 관리자 모드만 장면 참조/이전·다음/장면 시간 토글 제공. 학생 완료 모달도 장면 수 대신 강 진행률 표시.
6. 다음 강 자동 재생은 별도 설정으로 저장. 대표 확인에 따라 완료 모달에서 5초 안내 후 이동하며 취소 가능. 기존 자동 장면 넘김 설정은 새 동의로 간주하지 않음.
7. 반복 탐색 중 이전 플레이어의 pause 이벤트가 새 seek를 취소하던 회귀 수정. 탐색 시간을 즉시 표시하고 새 플레이어의 위치 확인 전에는 오래된 진행 이벤트를 무시. T 탐색은 일시정지하며, 강 ID 변경은 플레이어 상태를 초기화하고 같은 강의 RSC 갱신은 위치 유지.

## 브라우저 상호작용

임시 로컬 코드 픽스처로 다음을 검증했다. 픽스처/캡처 스크립트는 커밋하지 않았으며 서버 기록 액션·DB를 호출하지 않는다.

- 일반 장면 → 다음 장면 자동 재생.
- 퀴즈 설명 끝 정지, 오답 시 유지, 정답 시 재개.
- 슬라이더 설명 끝 정지, 계속 버튼으로 재개.
- 완료 모달 5초 카운트다운, 취소 후 유지, 다음 강 `?autoplay=1` 이동.
- 장면 간 앞/뒤 탐색 후 reveal 상태 복원.
- 새로고침 시 1,230ms 위치 복원, `#c` 진입 시 해당 장면 시작으로 이동.
- 목차 Esc·바깥 클릭 닫기·항목 이동, 집중 모드 Esc 전파 방지.
- 관리자 장면 막대/강 전체 막대 전환.
- 교육과정 단원 펼침 상태 새로고침 후 유지.
- 390px 화면 문서 가로 넘침 없음(scrollWidth 390).

검증 환경은 로컬 Chromium이다. 실제 음성 재생 대신 기존 자막 시계와 지정 문장 길이를 사용했다. 운영 로그인·실제 음원·실기기 iOS Safari 검증은 포함하지 않는다. 원본 JSON은 렌더 검사에 읽기만 사용했고, 생성 음원에는 접속하거나 재생성을 요청하지 않았다.
