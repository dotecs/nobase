# 뿌리깊은수학 무료 강의 — 전달 체계

네이버 톡톡에서 무료 강의를 신청한 사람에게 링크를 보내고, 시청 기록을 보고 상담으로 이어 가는 흐름.

## 흐름

1. 블로그·광고 → 네이버 톡톡(talk.naver.com/w4jod1)에서 무료 강의 신청
2. 톡톡 답변으로 **https://nobase911.com/free** 전달 (아래 ①)
3. /free: 20강 목록 · "1강 바로 보기"(로그인 없음) · "카카오 로그인하고 전체 보기"
4. 1강을 끝내면 "카카오 로그인하고 다음 강의" → 카카오 가입·로그인 → 2강부터 무료 시청
   - 이때 가입한 계정은 `profiles.lead_source = 'studio_free'`로 표시됨
5. 강의를 끝낼 때마다 완료 창에 **코칭 상담하기**(톡톡) 버튼
6. 관리자 › 학습 › **무료 강의 시청자**: 로그인 시청자의 이름·연락처·연 강의 수·완료 수·마지막 강의·마지막 활동 (수강생·관리자 제외)
7. 3일 뒤 톡톡으로 후속 메시지(②), 많이 본 사람은 상담 제안(③)

## 접근 규칙 (코드)

- 무료 범위: `content/curricula/root-math.json`의 모든 강의(1~20강) — `lib/learn/lessons/free-access.ts`
- 비로그인: 첫 강의(rm-01)만. 미들웨어 `lib/supabase-middleware.ts`의 `publicPaths`와 같아야 함(테스트로 확인)
- 로그인했지만 수강생 아님: 무료 강의 시청·기록 저장 가능, 연습 문제(적응형 학습)는 수강생 전용
- 비로그인 1강 시청은 기록되지 않음 → 톡톡 신청자 수 대비 로그인 전환율은 시청자 목록 인원으로 본다

## 운영 체크

- 톡톡 자동 응답에 ①을 넣으면 신청 즉시 링크가 나감
- 주 1회 관리자 › 무료 강의 시청자 확인 → 완료 수가 많은 순으로 ③
- 톡톡 대화 상대와 사이트 계정은 자동으로 연결되지 않음 — 상담 때 카카오 이름·연락처로 맞춰 본다
