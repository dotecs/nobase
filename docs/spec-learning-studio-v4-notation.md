## LS4-0. 정확한 수 표기 `formatExact`

`lib/learn/lessons/format-num.ts`에 `formatExact(value:number, mode:'tex'|'text'):string`을 추가하고, 아래 순서로 **처음 맞는 형태**를 돌려준다. 허용 오차는 1e-9(상대·절대 중 큰 쪽).

| 순서 | 형태 | tex 예 | text 예 |
|---|---|---|---|
| 1 | 정수 | `-3` → `−3` | `−3` |
| 2 | 분수 p/q (연분수로 q ≤ 64) | `\tfrac{7}{4}`, 음수는 `-\tfrac{7}{4}` | `7/4`, `−7/4` |
| 3 | π의 유리수 배 (value/π가 2번 형태, q ≤ 12) | `\tfrac{\pi}{2}`, `2\pi`, `-\tfrac{3\pi}{4}` | `π/2` |
| 4 | e의 유리수 배 (q ≤ 4) | `2e`, `\tfrac{e}{2}` | `2e` |
| 5 | 제곱근 꼴: value² 이 2번 형태 p/q이고 p/q가 완전제곱이 아닐 때. n = 분자·분모 정리 후 `\tfrac{\sqrt{n}}{q}` 또는 `\sqrt{n}`, 제곱 인수는 밖으로(`\sqrt{12}` → `2\sqrt{3}`) | `\sqrt{13}`, `\tfrac{\sqrt{13}}{2}`, `2\sqrt{3}` | `√13`, `√13/2` |
| 6 | `a ± √n` 꼴: (value·2 − 정수)² 등 — **이번엔 하지 않는다.** 콘텐츠가 라벨을 명시한다 |  |  |
| 7 | 그 밖 | 소수 둘째 자리, 끝 0 제거, 음수 기호 `−` | `1.73` |

- `formatNum`은 유지하되 내부에서 `formatExact(value,'text')`를 부르도록 바꾼다(기존 호출처 호환).
- 7번으로 떨어진 경우를 알 수 있도록 `isExact(value):boolean`도 내보낸다.
- 테스트: 위 표 각 행 2개 이상 + 경계(0, −0, 1e-12, 0.3333333333 → 1/3, 0.1+0.2 → 3/10, 1.3028 → 소수 그대로).

## LS4-1. 적용 위치

모두 `formatExact(…, 'tex')`를 KaTeX로 렌더한다. 소수 표기가 남는 곳이 없어야 한다.

1. **파라미터 패널 값** (`StageControls`: `a = 1`, `c = −3`): 슬라이더·스테퍼 모두. `<input type=number>`의 값은 숫자 그대로 두되 눈에 보이는 라벨은 exact.
2. **수식 자리표시자** `{{c}}` (`formulaValues`): 부호 합치기 규칙은 유지. `(a = \tfrac{1}{2})` 처럼 들어간다.
3. **슬라이더 verdict** (`sliderVerdict`의 `D = …`): 이미 `Rational`로 계산하므로 `Number(d.toFixed(6))` 대신 Rational을 그대로 tex로. `D = \tfrac{9}{4} − 4k` 같은 식 전개까지는 하지 않는다. 값만.
4. **그래프 점 라벨** `label:"auto"`: `(x, y)` 각 좌표를 exact로. 둘 중 하나라도 `isExact`가 false면 `lesson-check`가 **오류**로 잡는다("점 (1.3028, 0)의 좌표를 정확한 식으로 쓰거나 label을 명시하세요").
5. **bracket·arrow 라벨**은 문자열이라 그대로. 다만 콘텐츠 가이드에 "소수 금지"를 적는다(§LS4-3).
6. **축 눈금**: 정수만 찍으므로 변경 없음. 만약 눈금 간격이 1 미만이 되는 범위(예: y −0.5~0.5)가 오면 `\tfrac{1}{2}` 간격 분수 눈금을 찍는다. 테스트 1개.

## LS4-2. 점·파라미터 좌표를 식으로 적기 (스키마)

콘텐츠가 `1.3028` 대신 정확한 식을 쓸 수 있어야 한다. `lib/learn/mathcheck/parse.ts`의 `parseMath`와 `evaluate`를 재사용한다.

- graph/slider stage의 `points[].x`, `points[].y`, chalk 액션의 `position.x/y`, `arrow_to`, `bracket.from/to`, `circle rx/ry`, slider `param.min/max/step/init`에 **숫자 또는 문자열 식**을 허용한다.
  - 허용 식: 정수·분수·`sqrt(…)`·`pi`·`e`·사칙연산·괄호. 변수 불가.
  - 예: `"x": "(-1+sqrt(13))/2"`, `"step": "1/4"`, `"position": {"x": "pi/2", "y": 0}`.
- 스키마에서 `z.union([finite, exprString])`으로 받고, `preprocess`로 **숫자로 평가해 내부 타입은 지금처럼 number로 유지**한다. 즉 렌더러·`stageStateAt`·테스트는 바뀌지 않는다.
- 단, 점의 `label:"auto"`일 때는 원래 식이 있으면 **식을 tex로 변환해 라벨에 쓴다**(`inspectMath` 재사용). 식이 없고 숫자만 있으면 LS4-0의 `formatExact`.
  - 이를 위해 점 객체에 내부 필드 `x_tex?`, `y_tex?`를 전처리에서 채운다(JSON에는 없음).
- `lesson-check`: 식이 파싱되지 않으면 오류. 식이 있는데 `label`이 없으면 경고 없이 통과(라벨 없음 = 표시 안 함, 현재 규칙).

## LS4-3. 자막 의미 단위 분절

현재 `captions.ts`는 32자마다 끊는다. 다음 규칙으로 바꾼다.

1. 문장 `text`를 먼저 **문장 끝**(`.` `?` `!` `…` 와 그 뒤 따옴표/괄호)에서 나눈다. 수식 `$…$` 안의 마침표는 제외.
2. 한 문장이 **38자**(공백 포함, 수식은 spoken 길이 대신 **표시 글자 수**로 센다)를 넘으면 그 안에서 **쉼표·닫는 따옴표·`—`** 뒤에서 나눈다. 후보가 여럿이면 중앙에 가장 가까운 것.
3. 그래도 넘으면 **연결 어미 뒤 공백**(`~고 `, `~면 `, `~는데 `, `~니까 `, `~지만 `, `~서 `, `~며 `)에서 나눈다. 후보가 여럿이면 중앙에 가장 가까운 것.
4. 그래도 넘으면 마지막 수단으로 공백에서 중앙 분할.
5. **합치기**: 나눈 조각이 12자 미만이면 앞 조각에 붙인다(단, 붙인 결과가 38자를 넘지 않을 때). "않죠."처럼 짧은 꼬리가 혼자 남지 않게 하기 위함.
6. 콘텐츠가 직접 끊고 싶으면 `text` 안에 `⏎`(U+23CE) 를 쓰면 그 자리에서 **반드시** 나눈다. 표시·음성 대본·anchor에서는 제거한다. (`text`는 `audioHash`에 들어가지 않으므로 음성 재생성 없음을 테스트로 보장.)

- 조각 경계는 단어 단위 하이라이트(`CaptionWord.chunk`)에 그대로 반영한다. 2줄 제한은 유지.
- 테스트: rm-11 s1-4 `"파란 그래프는 두 번 만나고, 청록 그래프는 한 번 스치고, 주황 그래프는 $x$축 위에 떠서 한 번도 만나지 않죠. 이 셋을 구분해 주는 숫자 하나를 오늘 배웁니다."` → 기대 조각: `파란 그래프는 두 번 만나고, 청록 그래프는 한 번 스치고,` / `주황 그래프는 $x$축 위에 떠서 한 번도 만나지 않죠.` / `이 셋을 구분해 주는 숫자 하나를 오늘 배웁니다.` 외 4개.
- `scripts/lesson-check.mjs`에 `--captions` 옵션: 레슨의 모든 문장을 조각으로 나눠 출력한다(Claude가 콘텐츠 검수에 쓴다).
