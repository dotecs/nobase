- 기준: main `15c98d0` 이후. 브랜치 `feat/learning-studio-pointing`.
- 배경(대표 지시 2026-11-04): ① 수직선 눈금 숫자가 작고 흐려 필기 수식과 이질적 → **이미 반영**(눈금을 KaTeX·본문색 20px로). ② 수직선 점의 손글씨 라벨이 점 바로 아래가 아니라 비스듬히 놓여 어느 점의 값인지 모호 → 기본 위치를 점 바로 아래 중앙으로 **이미 반영**(`label_pos` n/s 추가). 남은 것은 **겹칠 때의 처리와 화살표 끝점의 정밀도**를 구조적으로 보장하는 일.
- DB·콘텐츠 JSON·음성·push·배포 금지. 기존 JSON 전부 검사 통과 유지.

## 1. 점 라벨 자동 배치 + 인출선(leader)

- 수직선(`number_line`)·그래프 모두, 점 라벨은 기본 위치(수직선 `s`, 그래프 `ne`)에 두되 **같은 무대의 다른 라벨·눈금 숫자·점과 bbox가 겹치면** 다음 순서로 피한다: (1) 반대편(`n`/`sw`) (2) 한 단 아래로 밀기(stack, 라벨 높이 + 6px) (3) 그래도 안 되면 **인출선**: 라벨을 빈 곳(점에서 가장 가까운 겹치지 않는 자리, 우선 아래쪽)으로 옮기고 라벨 가장자리에서 점 테두리(반지름 6px 바깥 2px)까지 가는 가는 선(`--studio-text` 60%, 1.2px)을 그린다. 선 끝에 화살촉은 없고 점에 닿는다.
- 겹침 판정은 렌더 후 측정(`useTargetBoxes`와 같은 bbox)으로 하고, 측정 전 첫 프레임은 기본 위치로 그린다. 재측정 루프가 흔들리지 않게 배치 결과를 라벨 수·위치 키로 메모한다.
- 저자가 `label_pos`를 명시하면 자동 배치는 **그 위치 기준으로 겹칠 때만** 인출선을 쓴다(위치는 바꾸지 않음).
- `label_offset: {x, y}`(px) 선택 필드를 점에 추가 — 저자가 미세 조정할 때 쓴다.

## 2. 화살표 끝점(arrow_to) 정밀도

- 지금은 `arrow_to.target`이 bbox **중심**으로 간다. 글자 위에 화살촉이 겹친다. 바꾼다: 화살표 끝 = 시작점에서 대상 bbox 중심을 잇는 선분이 **bbox 경계와 만나는 점에서 4px 바깥**. 점(`point:i`)은 반지름 6px 원 바깥 3px. 눈금(`tick:<값>`)도 대상으로 허용(`axis` 눈금 라벨 bbox).
- `arrow_to.anchor` 선택 필드: `edge`(기본, 위 규칙) | `center` | `top` | `bottom` | `left` | `right` (bbox 해당 변의 중점 4px 바깥). 분수의 분자/분모를 가리킬 때는 좌표를 직접 주는 대신 `anchor:"top"`/`"bottom"`으로 해결되게.
- 손글씨 메모 시작점은 LS4-8대로 실제 글자 경계. 곡선은 시작·끝 둘 다 경계에 닿도록 재계산(지금은 시작만).
- `arrow` 액션(from/to가 target인 경우)도 같은 규칙.

## 3. figure 무대 좌표계

- items·chalk의 비율 좌표(0~1)를 **카드 전체가 아니라 렌더된 이미지 박스** 기준으로 바꾼다(object-fit: contain으로 생긴 여백 제외). 이미지 크기 변화에 따라 재측정. rm-08 s1이 모든 화면 비율에서 정사각형 위에 라벨이 놓여야 한다.

## 4. 글자 크기 일관성

- 수식이 들어가는 모든 자리(손글씨·items·steps·chain·표 셀·점 라벨)는 `\displaystyle`로 렌더한다 — 손글씨·items·steps·chain은 **이미 반영**. 표 셀·quiz 보기·`why`도 같은 규칙으로 맞추고, 분수가 들어가도 분자·분모 글자 크기가 본문과 같은지 테스트로 고정(KaTeX `.mfrac` 내부 font-size 1em).
- 눈금 숫자(20px)·점 라벨(23px)·손글씨(28px 기준)·items md(26px)의 크기 사다리를 CSS 변수로 묶어 한 곳에서 조정 가능하게(`--studio-type-tick`, `-label`, `-hand`, `-item`).
