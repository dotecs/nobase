# LS2-6 콘텐츠 인계 — 2026-10-30

콘텐츠와 seed는 명세대로 Claude 담당이다. 이 작업은 저장소의 rm-11·rm-11-w1 호환 및 음성 재사용 모의 검증만 수행했다. 레슨 JSON·개념 seed를 수정하거나 DB·스토리지·유료 음성 API에 쓰지 않았다.

## 검증

- 두 레슨의 모든 문장을 이전 버전 음성 행으로 모의 구성했다.
- 새 버전에 시간 앵커와 인라인 마커를 넣어도 발화 대본·해시는 그대로다.
- 새 버전의 모든 음성 행이 이전 경로를 공유하며, 음성 요청·업로드 바이트는 0건이다. 정렬 null도 유지되어 선형 폴백으로 재생할 수 있다.
- 실제 운영 v3의 재생성 0건 여부는 062 적용과 seed 후 Claude가 확인한다. 이 모의 결과가 운영 검수를 대신하지 않는다.

## Claude 작업

1. 062 파일 적용 후 rm-11·rm-11-w1 v3 콘텐츠 작성·seed.
2. 시간은 `at:"@파란"`, 좌표는 `position:{x,y}`로 구분한다. 기존 `at:{x,y}`와 숫자 `at_ms`도 입력 호환된다. 예: `{type:"circle", at:"@판별식", position:{x:1,y:2}, rx:1, ry:1}`.
3. `⟨p1⟩` 마커는 글자 사이에 추가하고 주변 공백·발화 대본을 바꾸지 않으면 기존 해시를 보존한다.
4. `npm run lesson:check -- <파일> --timeline` 실행. 필요하면 `--alignment <문장ID별 정렬 JSON>`으로 실제 시각을 표시한다.
5. 그래프 등축, 단어 자막·앵커 동기화, 1.5배·스크럽, 칠판 수명과 reduced-motion을 운영 음성으로 검수한다.

키가 없으면 관리 화면은 키 없음만 표시한다. 정렬 없는 기존 음성의 재사용은 재생성하지 않으며, **정렬 다시 받기**를 선택했을 때만 명시적으로 재생성한다.
