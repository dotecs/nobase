# LS4-10 검수 기록

2026-11-04 · feat/learning-studio-pointing

## 구현

- tint를 item·step·node·row·cell·tree에 적용하고 다중 색, TTL, clear·되감기를 지원했다.
- callout은 대상 경계에서 6px 떨어진 지름 8px 점, 1.5px 꺾임선, 9px 화살촉, 본문 수식 주석을 순서대로 그린다. 4방향 앵커와 직선 경로, 직접 좌표를 지원한다.
- 대표 답변에 따라 callout의 ttl_ms 기본값은 0이다. 명시한 유지 시간이 있으면 만료된다.
- 이름 있는 주석은 item:id로 참조할 수 있다. 주석 배치는 실제 측정한 폭·높이와 원래 좌표로 매번 계산해 겹칠 때 아래로 이동한다.
- board 그룹은 첫 항의 위치를 중심으로 실제 렌더 폭과 gap을 사용해 한 줄로 배치한다. 숨긴 항은 폭을 예약해 공개 시 이웃 항의 이동을 방지한다.
- headline.accent_bar를 상단 제목과 집중 모드 제목에 적용했다.
- 데모의 expression-callout 장면에 네 항, 민트 tint, 아래 callout을 추가했다.

최신 명세와 선행 헤더·색 변경은 origin/main의 cf47dce까지 병합했다. 병합 커밋은 711d4f2다.
