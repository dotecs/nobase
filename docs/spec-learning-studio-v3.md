## 1. 디자인 토큰 (LS3-0)

`styles/globals.css`의 `[data-studio]` 블록에 추가하고 기존 토큰은 유지한다. 색은 컴포넌트에 하드코딩하지 말고 반드시 토큰으로 참조한다.

```css
[data-studio] {
  /* 지시 요소: 빨간 네온 */
  --studio-mark: #ff3b5c;
  --studio-mark-core: #ffd6dd;          /* 네온 중심부의 밝은 심 */
  --studio-mark-glow: rgba(255, 40, 80, .55);
  /* 손글씨 메모: 시안 하늘색 네온 */
  --studio-hand: #4cc9f0;
  --studio-hand-glow: rgba(76, 201, 240, .45);
  /* 곡선 네온 (기본 곡선색 = accent) */
  --studio-curve-glow: rgba(56, 189, 248, .45);
  --studio-card: color-mix(in srgb, var(--color-gray-900) 70%, transparent);
  --studio-card-border: rgba(120, 160, 210, .22);
  --font-hand: 'Poor Story', var(--font-sans);   /* next/font variable로 주입 */
}
[data-studio][data-theme="light"] {
  --studio-mark: #e11d48;
  --studio-mark-core: #e11d48;
  --studio-mark-glow: rgba(225, 29, 72, .22);
  --studio-hand: #0284c7;
  --studio-hand-glow: rgba(2, 132, 199, .18);
  --studio-curve-glow: rgba(2, 132, 199, .2);
  --studio-card: rgba(255, 255, 255, .85);
  --studio-card-border: rgba(15, 23, 42, .12);
}
```

### 필기체 폰트: Poor Story

- 시안의 손글씨 자형(ㅋ·질·록·좁)과 거의 같은 폰트로 **Poor Story**(Google Fonts, SIL OFL)를 확정했다. 비교 결과는 `docs/learning-studio-v3-font-match.png`에 있다. Gaegu, 나눔손글씨 펜, Hi Melody 등 8종과 비교했다.
- 적용 방법:
  - `next/font/google`의 `Poor_Story({ weight: '400', display: 'swap', preload: false, variable: '--font-hand' })`를 쓴다.
  - **스튜디오 라우트(`app/(main)/learn/lesson/[id]`, `/learn/studio-demo`)에서만** 로드해 다른 페이지의 전송량을 늘리지 않는다.
  - 한글 글리프는 unicode-range 조각으로 받아지므로, 실제로 한글이 Poor Story로 그려지는지 확인한다(`document.fonts.check("16px 'Poor Story'", '가')`).
  - next/font에서 한글 조각이 빠지면 `@fontsource/poor-story`로 자체 호스팅한다(이것도 해당 라우트에서만).
- 쓰는 곳: 손글씨 메모(`handwrite`), 화살표 라벨(`arrow.label`). 모든 경우 `font-family: var(--font-hand)`를 쓴다.
- 쓰지 않는 곳: 수식(KaTeX), 축 눈금, 자막, UI 텍스트.
- 크기: 메모 기본은 무대 좌표 기준 28px(시안 기준)이고 줄 간격은 1.3이다. 시안처럼 −4° 기울이며, 콘텐츠에서 `rotate`로 바꿀 수 있다.

### 네온 표현 공통 규칙

- 선은 두 겹으로 그린다. 바깥 글로우 선(굵기 ×3, `--*-glow`, `filter: blur(3px)`) 위에 본선(`--studio-mark` 또는 `--studio-hand`)을 올린다.
- 또는 `<g>`에 `filter: drop-shadow(0 0 3px var(--*-glow)) drop-shadow(0 0 10px var(--*-glow))`를 건다. 어느 방식이든 Safari(iOS)에서 확인한다.
- 라이트 테마에서는 글로우를 약하게 하고 본선 대비를 우선한다.
- `prefers-reduced-motion`: 그려지는 애니메이션만 생략하고 색과 글로우는 유지한다.

### 2-1. 과정 사이드바

데이터 원천은 `content/curricula/root-math.json`이다. Claude가 작성해 레포에 넣어 두었다.

- 구조: `{id, title, chapters:[{no, title, items:[{no, title, lesson_id, worked?:[{title, lesson_id}]}]}]}`
- 레슨의 `pack_id`(`root-math`)로 파일을 찾는다. 서버 컴포넌트에서 import한다(번들에 포함, DB 조회 없음).
- 각 `lesson_id`가 열람 가능한지(reviewed/live 버전 존재)는 서버에서 `learn_lessons`를 한 번에 조회해 판정한다. 쿼리는 1회만.

**현재 강의 카드** (시안 좌상단):
- `현재 강의` 라벨(accent, 작게)
- 레슨 `title`(굵게, 20px 내외)
- `학습 목표` 라벨과 레슨의 새 선택 필드 `goal`. 없으면 `intro`를 쓴다.
- 진행 막대와 `n / N`. N은 장면 수, n은 지금까지 지나온 장면 수(현재 장면 포함).

**전체 교육 과정 아코디언**:
- 챕터 행 형식은 `01  수와 식  ⌄`이다. 현재 레슨이 속한 챕터만 기본으로 펼친다.
- 펼친 챕터 안의 항목은 세로 타임라인 점과 선으로 잇는다(시안 하단).
  - 현재 레슨: 강조 배경의 행, accent 링 점, accent 글자.
  - 열람 가능한 레슨: 회색 점이고 클릭하면 이동한다.
  - 준비 중인 레슨: 흐린 점과 흐린 글자, `준비 중` 표시, 클릭할 수 없다(`aria-disabled`).
- 항목 제목은 `11 이차방정식의 판별식`처럼 번호와 제목을 붙여 쓴다.
- `worked`(문제풀이)는 해당 강의 항목 아래 한 단계 들여 쓴 하위 행으로 표시한다. 현재 레슨이면 같은 강조 규칙을 적용한다.
- 완료 표시(선택): `learn_lesson_events`에 레슨 완료 이벤트가 이미 기록되고 있다면 완료 항목의 점을 채워 표시한다. 기록되지 않고 있다면 이번 범위에서는 하지 않는다(새 이벤트 타입을 추가하지 말 것).

## 3. 무대 카드 머리 (LS3-2)

- **좌: 장면 제목.** 3px × 22px accent 세로 막대 뒤에 제목을 붙인다.
  - 제목은 `headline.title`의 줄바꿈을 공백으로 바꾼 것이다. 길면 1줄 말줄임하고 전체 문구는 `title` 속성에 넣는다.
  - `headline.eyebrow`는 제목 위에 작게(12px, muted) 둔다. 시안에는 없지만 정보 손실을 막기 위해 둔다.
  - `subtitle`은 표시하지 않는다(내레이션과 중복).
- **가운데: 장면 수식.** 장면의 새 선택 필드 `headline.formula`(TeX)를 KaTeX로 렌더한다(32px 내외).
  - 문자열 안의 `{{a}}` 같은 자리표시자는 해당 파라미터의 현재 값으로 치환한다(숫자 표기는 §4-3 규칙).
  - 슬라이더나 내레이션 `param` 액션으로 값이 바뀌면 즉시 반영한다.
  - 예: `"y = ax^2 \\quad (a = {{a}})"`
  - `formula`가 없으면 가운데를 비운다.
- **우: 파라미터 패널.** 시안처럼 작은 카드 안에 `a = 1` 라벨과 `[−] [ 1 ] [+]` 스테퍼를 둔다.
  - 기존 stage controls 정의(min/max/step)를 그대로 쓴다.
  - 컨트롤 정의에 `control: "slider"`가 명시된 경우에만 슬라이더를 쓰고, 기본은 스테퍼다.
  - 내레이션이 값을 움직이는 동안에는 값이 따라 바뀌고, 사용자가 누르면 기존 v2 규칙(사용자 조작이 우선)을 따른다.
- 머리 영역 높이는 고정(약 88px)이다. 그림 영역은 남은 높이를 차지하고 하단에 자막 높이만큼 여백을 둔다(기존 captionHeight 측정을 재사용).

## 4. 그래프 시각 (LS3-3)

### 4-1. 등축 맞춤 규칙 (버그 수정)

- 현재 `aspect:'equal'`은 가로를 기준으로 맞추면서 세로가 잘린다. rm-11 s1에서는 y≈−0.5~2.5만 보여 주황 곡선이 화면 밖으로 나갔다.
- **규칙:** 선언된 x 범위와 y 범위가 **둘 다 온전히 보이도록** 축척 하나를 고른다(`min(w/Δx, h/Δy)`). 남는 방향은 범위를 양쪽으로 넓혀 채운다. 어느 축도 선언 범위보다 좁아지면 안 된다.
- 단위 테스트를 추가한다. 가로로 긴 무대와 세로로 긴 무대 각각에서 선언 범위 네 모서리가 모두 보이는지 확인한다.

### 4-2. 선과 축

- 곡선: 본선 2.5px에 네온 글로우(§1)를 얹는다. 기본색은 accent이고, 함수별 `c` 팔레트는 유지하되 같은 글로우 방식을 쓴다.
- 축: 양의 방향 끝에 화살촉을 단다. 축 이름 *x*, *y*는 KaTeX_Math 이탤릭(또는 serif italic)으로 쓴다.
  - 눈금은 정수이고 원점 눈금 `0`은 원점 좌하단에 둔다.
  - 눈금 간격은 화면상 40px 이상 유지한다. 좁으면 2, 5 단위로 솎는다.
- 격자: 무대 안 격자는 매우 옅게 하거나 없앤다. 시안은 페이지 배경 격자만 보인다.

### 4-3. 점과 라벨

- 점은 속이 빈 링이다. 반지름 6px, 흰 테두리 2px, 안쪽은 무대 배경색, 바깥에 곡선색 글로우.
- 점의 새 선택 필드:
  - `guides: true`: 점에서 x축과 y축까지 점선(1px, `--studio-muted`, dash 4 4)을 긋는다. 시안의 (1, 1), (2, 4).
  - `label`: 문자열이면 **KaTeX**로 렌더한다. 예: `"(2, 4)"`, `"\\left(\\tfrac13, 0\\right)"`.
  - `label: "auto"`: 좌표를 표기 규칙대로 자동 생성한다.
  - `label`이 없으면 라벨을 그리지 않는다. **현재처럼 좌표를 자동으로 표시하는 동작은 없앤다.**
- **숫자 표기 규칙** `formatNum`(라벨, 수식 자리표시자, 파라미터 패널 공용):
  - 정수는 정수로 쓴다(`2`).
  - 그 밖에는 소수 둘째 자리까지 쓰고 끝의 0을 지운다(`1.3`, `-2.3`).
  - 음수 기호는 `−`(U+2212)로 쓴다.
  - `toFixed(3)` 사용처(`StudioGraph.tsx`)를 이 함수로 교체한다.
- 라벨 위치는 기본 우상단 (+12, −12)이다. `label_pos: "ne"|"nw"|"se"|"sw"`로 바꿀 수 있다.
- 라벨 뒤에는 무대 배경색 테두리(paint-order stroke)를 둬서 곡선과 겹쳐도 읽히게 한다.

## 5. 칠판 레이어 (LS3-4)

### 5-1. 색 정책

| 요소 | 기본 색 | 지속 |
|---|---|---|
| pointer · circle · underline · arrow · bracket · shade · flash | **빨간 네온** `--studio-mark` | 기존 `ttl_ms`(기본 2500) 후 사라짐. 현재 동작 유지 |
| handwrite(손글씨 메모) | **하늘색 네온** `--studio-hand` + Poor Story | 기본은 장면 끝까지 유지(`ttl_ms` 생략 시). `ttl_ms` 값이 있으면 그 시간 뒤 사라짐 |

- 색 enum을 `color: 'mark' | 'hand' | 'chalk'`로 정리한다.
  - 생략하면 위 표의 기본색을 쓴다.
  - 기존 `'accent'`는 `'hand'`의 별칭으로 계속 받는다(이미 seed된 v1~v3가 깨지지 않게).
  - `'chalk'`는 흰색으로 남겨 둔다.
- 빨간 네온 세부:
  - pointer의 퍼지는 링(ring)은 `--studio-mark`이다.
  - shade의 빗금은 `--studio-mark`의 불투명도 .35, flash의 채움은 `--studio-mark`의 불투명도 .14로 한다.
  - 사라질 때 200ms 동안 서서히 흐려진다(지금 바로 사라지는 경우가 있으면 맞출 것).

### 5-2. 손글씨 메모 + 화살표 (시안 우상단)

`handwrite` 액션에 선택 필드를 추가한다.
- `arrow_to: {x, y}` 또는 `{target: "point:1"}`: 메모 시작점 근처에서 대상까지 **손으로 그린 곡선 화살표**를 긋는다. 이차 베지어로, 제어점은 직선 중점에서 수직으로 15% 휘게 한다. 화살촉은 두 획이다. 색은 메모와 같다.
- `rotate`: 기본 −4이다.
- `align: "start" | "middle"`: 기본 start이다.

그리는 순서는 화살표(400ms) 다음 글자 쓰기(기존 clip 애니메이션)다. 시작 시각은 기존 `at` 앵커를 그대로 따른다.

### 5-3. 버그 수정: `underline target:"axis:x"`

- 현재는 무대 맨 아래에 그어진다. **실제 x축 선(y=0) 위에 겹쳐**, 보이는 x 범위 전체에 긋는다. `axis:y`도 같은 방식으로 x=0 위에 긋는다.
- `from`/`to`(데이터 좌표)가 있으면 그 구간만 긋는다.
- 테스트: 등축 그래프와 비등축 그래프 둘 다에서 밑줄의 화면 y가 x축의 화면 y와 같아야 한다(±1px).

## 6. 자막 (LS3-4와 함께)

- 위치는 무대 카드 안쪽 하단 중앙이다(카드 하단에서 16px).
- 모양: 어두운 알약(`rgba(8,14,26,.82)`, 라이트 테마는 `rgba(255,255,255,.92)`), radius 8px, 좌우 패딩 18px, 글자 20px / weight 500.
- v2의 단어 단위 진행 표시(이미 말한 부분은 밝게, 남은 부분은 흐리게)와 2줄 제한은 유지한다.
- 하단 바의 `자막` 버튼을 끄면 숨긴다. 숨겨도 그림 영역의 하단 여백은 유지해서 레이아웃이 튀지 않게 한다.

## 7. 하단 바 (LS3-5)

한 줄에 왼쪽부터 다음 순서로 놓는다.

1. `← 이전 내용` 버튼(외곽선형). 첫 장면에서는 비활성.
2. **재생 바 카드**(가운데, 늘어남): 원형 재생/일시정지(accent 채움), 진행 슬라이더(accent 채움, 원형 손잡이), `01:24 / 03:10`, 속도 select(`1×`), `자막` 토글. 기존 `Transport` 기능과 키보드 조작은 유지한다.
3. **장면 페이저**: `‹  02 / 04  ›`. 기존 점 내비는 제거한다. 좌우 화살표는 이전/다음 장면이고 숫자는 tabular-nums.
4. `다음 내용 →` 버튼(accent 채움). 마지막 장면에서는 `학습 마치기`. v2의 장면 종료 시 강조(`data-ended`)는 유지한다.

재생 시간은 현재처럼 **장면 단위**(그 장면 내레이션 길이)로 표시한다.

## 8. 반응형 · 집중 모드 · 녹화 프레임 (LS3-6)

- **1280px 이상**: 시안 그대로.
- **1024–1279px**: 사이드바를 접는다. 상단 바 왼쪽에 `과정` 버튼을 두고 누르면 왼쪽 드로어로 연다. 무대는 전체 너비를 쓴다.
- **1023px 이하(모바일 포함)**:
  - 사이드바는 드로어로만 연다.
  - 무대 카드 머리는 2줄이다. 1줄은 제목과 파라미터, 2줄은 수식(가운데).
  - 하단 바도 2줄이다. 1줄은 재생 바, 2줄은 `이전` · 페이저 · `다음`.
  - 손글씨 메모는 무대 좌표 기준이라 함께 축소된다. 최소 글자 14px을 보장하고, 그보다 작아지면 축소를 멈추고 잘리지 않게 위치를 안쪽으로 당긴다.
- **집중 모드**: 사이드바와 상단 바를 숨기고 무대 카드와 하단 바만 남긴다. 2초 동안 조작이 없으면 하단 바를 숨기는 기존 규칙은 유지한다.
- **`?frame=16x9&chrome=0`**: 무대 카드와 자막만 남긴다. 사이드바, 상단 바, 하단 바는 숨긴다.

## 9. 스키마 · 검사 도구

`schema.ts`, `chalk-schema.ts`, `scripts/lesson-check.mjs`에 다음 **선택 필드**를 추가한다. 기존 v1~v3 JSON은 그대로 통과해야 한다.
- lesson: `goal?: string`(최대 120자)
- scene.headline: `formula?: string`(TeX, 최대 300자, `{{param}}` 자리표시자는 해당 stage에 정의된 파라미터 이름만 허용)
- graph point: `guides?: boolean`, `label?: string | "auto"`, `label_pos?: 'ne'|'nw'|'se'|'sw'`
- graph stage control: `control?: 'stepper' | 'slider'`
- chalk `color`: `'mark'|'hand'|'chalk'|'accent'`(accent = hand 별칭)
- handwrite: `arrow_to?`, `rotate?: number`(−15~15), `align?`

`lesson-check`가 추가로 잡아야 할 것:
- 존재하지 않는 파라미터를 가리키는 `formula` 자리표시자(오류).
- 한 장면에 손글씨 메모가 4개를 넘음(경고).
- `label`이 KaTeX 파싱에 실패함(오류).

### studio-demo 갱신 (LS3-7)
