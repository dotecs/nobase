## 1. 대본 구조

- `kind:"concept"`, 장면 5~7개, 문장 18~28개. 첫 문장 "이번 시간에는 …"(인사 금지), 마지막 문장 "다음 시간에는 n강 ○○입니다."
- 장면 순서: 정의 → 교재 예시 → (거꾸로·주의) → 확인 퀴즈(`tag:"check"`, `quiz`, `trace_concept_id`).
- `headline`: eyebrow `"n강 · 제목"`, title 짧게, accent는 title의 부분 문자열. **`formula` 금지**(수식은 items).
- 전후 참조: 뒤로 "n강에서 배운 ~"(실제 앞 강 내용만), 앞으로 "n강에서 배울 내용이라 이름만"(손글씨 `→ n강 ○○`). 번호는 말로도 붙인다. 이 과정 밖(지수함수 단원 등)은 번호 없이.
- **근은 개수가 아니라 종류로 말한다**(대표 지시 2026-11-05): 중근은 "근이 1개"가 아니라 "두 근이 겹친 것". 제곱근·이차방정식 모두 "서로 다른 두 실근 / 서로 같은 두 실근(중근) / 실근 없음(두 허근, 이름만)" 세 종류로 설명한다. "근이 1개", "근이 0개", "근의 개수" 표현 금지(교점의 개수는 가능). 이렇게 해야 뒤에서 "n차 방정식의 근은 n개"와 모순이 없다. 기준 문장은 rm-08 s4-4~s4-6, rm-11 s3-3·s3-4.
- 방정식·부등식은 **의문문**으로 먼저 번역(5강: "x가 무엇이면 참이 되느냐", 11강 이후: 두 그래프의 교점).

## 2. 무대 선택

| 내용 | 무대 | 메모 |
|---|---|---|
| 식 한 줄 놓고 부분 가리키기 | `board` + items `group` | 항마다 item. 같은 식의 항은 `group:"expr"`로 묶어 **자동 한 줄 배치**(첫 item에만 `position`(그룹 중심)·`gap`(기본 0.6em), 연산자는 다음 항 tex 앞에 붙임 `-2x^2y`). 글자 폭을 어림해 x를 네 번 적지 않는다. 식 구조 설명 장면은 `size:"xl"` |
| 유도·변형 | `steps` (`why` + `concept_id`) | 현재 줄만 밝고 나머지는 흐려짐(highlight dim_others). 한 문장에서 줄 2개를 다루면 둘 다 highlight |
| 경우 비교·성질 나열 | `table` (`tone`) | **chain 카드 6개는 좁아서 깨진다** → 4개 초과면 table. 표 머리글과 셀 모두 `$…$` 수식 가능 |
| 분류 | `tree` | |
| 수직선 | `graph` + `number_line:true` | 점은 `label:"auto"`(짧은 세로 선으로 표시). **부등식의 해는 `region`**(채운 원/빈 원·무한 화살촉·조건별 level), 길이·이름 표시는 `bracket` |
| 값 바꾸며 관찰 | `slider` | step은 분수 문자열, 꼭짓점이 y 범위 밖으로 안 나가게 param 범위 조정 |
| 도형(정사각형 등) | `figure` + items·chalk | 이미지 또는 SVG 위에 비율 좌표(0~1)로 items·지시를 배치. 좌표는 **letterbox 여백을 뺀 실제 이미지 박스** 기준(LS4-9). items 없이도 좌표 지시 가능 |

좌표: graph/slider는 데이터 좌표, 나머지는 비율(0~1, 좌상단 원점). **새로 쓰는 메모·callout·items는 비율 좌표 대신 대상 기준 `position:{"near":"item:a","side":"below","gap":12}`를 기본으로**(side: below/above/left/right). 가로·세로 화면에서 같은 규칙으로 놓인다.

세로(모바일, 폭 640px 미만)는 엔진이 다시 배치한다(LS4-13): 칠판을 축소하지 않고 실제 글자 크기로, 식 그룹은 항 단위 줄바꿈, 그룹 밖 items는 JSON 순서(또는 `order`)대로 세로 스택, 3열 이상 표는 행을 카드로, callout·손글씨는 대상 옆에 붙고 대상 없는 손글씨는 아래 메모 영역에 순서대로. 저자가 할 일: (1) items의 JSON 순서를 읽는 순서로 둔다, (2) 손글씨는 가능한 한 `arrow_to.target`을 준다, (3) 비율 좌표는 가로 전용이라 생각한다. **steps·table 무대에서 손글씨를 쓰려면 item이 1개 이상 있어야 비율 좌표로 해석된다**(없으면 검사 오류).

## 3. 지시(chalk) 규칙

**식 구조 설명은 callout, 구어체 메모는 손글씨.** 손글씨(노란 Poor Story)는 "→ 7강 지수법칙", "(+)" 같은 짧은 구어체 메모에만 쓰고, 항·계수·지수를 설명하는 주석은 `callout`으로 쓴다(rm-02 s1~s4가 기준 예).

- `tint`: `{"type":"tint","target":"item:t1","color":"mint","at":"@…"}` — 요소 글자색만 바꿈. 기본 ttl 0(장면 끝까지). 색 `mint`(기본 강조)·`accent`·`mark`·`hand`. 항 전체 단위(`item:<id>`, `step:i`, `row:i` …), 부분(`item:t1/coef`)은 안 된다.
- `callout`: `{"type":"callout","id":"c1","target":"item:t1/coef","anchor":"bottom","text":"$x^3$의 계수 **4**","color":"mint","position":{"x":0.3,"y":0.5},"at":"@…"}` — 대상 가장자리 6px 바깥의 점 → 직각 꺾임선 → 화살촉 → 본문 폰트 주석. `tex` 또는 `text`(굵게·인라인 수식 가능). `position`은 주석의 **상단 중앙**. 대상은 부분(`item:t1/coef`, `item:t1/exp`)도 된다. 기본 ttl 0; 잠깐 보일 것만 `ttl_ms`. `id`를 주면 `item:c1`으로 highlight·underline 대상이 된다. 위쪽 주석은 `anchor:"top"`, y≈0.08.
- 배치 기준(16:9 board, 식 y 0.3·xl): 주석 y 0.5, 정의 메모(`kind:"note"`) y 0.66~0.85. 주석 여러 개는 x를 0.15~0.2 간격으로.

- **언급하면 가리킨다(필수)**: 내레이션이 칠판 위 요소(항·계수·점·표의 행·단계·정의 메모·트리 노드)를 말로 언급하는 순간, 그 요소에 반드시 지시가 붙는다 — 실제 수업에서 선생님이 분필로 짚듯이. 특정 값·항·점은 `circle`, 행·단계·정의 메모·긴 식은 `underline` 또는 `highlight`(steps·table), 식의 부분은 `circle target:"item:t1/coef"`. 앵커는 그 요소를 읽는 tts 단어. 같은 요소를 한 문장에서 두 번 말하면 처음 한 번만. reveal·callout·tint도 지시로 친다. 예외: "이번 시간에는 …" 도입, 퀴즈 안내, 다른 강 예고처럼 칠판 요소를 말하지 않는 문장.
- **가장 작은 요소를 가리킨다**: 말하는 대상이 식의 한 부분이면 행·줄 전체가 아니라 그 부분(`\p{…}`로 표시한 계수·지수·인수·결과값)을 가리킨다. "모두 약분되어" → 약분되는 인수마다 차례로 `strike`(빗금), "1이 됩니다" → 그 `1`에 `circle`. 행·줄 전체 underline은 그 줄 전체를 말할 때만. (LS4-12 전까지는 표 셀·steps에 부분 대상이 없으므로 items로 옮기거나 줄 단위로 둔다.)
- **지시는 문장과 함께 사라진다**: pointer·circle·underline·strike·arrow·flash·tint는 그 문장 음성이 끝나면 자동으로 사라진다(LS4-12). 장면 끝까지 남겨야 하면 `until:"scene"`을 명시. 손글씨·callout·region·bracket은 칠판에 적힌 내용이라 장면 끝까지 남는 것이 기본.
- 문장당 1~3개. pointer·circle은 문장당 2개 이하(넘치면 underline·highlight로), 손글씨는 장면당 4개 이하.
- **ttl 기본값은 2.5초**(손글씨만 영구). 장면 끝까지 남겨야 하는 것(해 구간 bracket, 정의 밑줄 등)은 반드시 `"ttl_ms":0`. 잠깐 가리키는 것은 4000~9000.
- 대상은 요소 기준(`item:<id>`, `step:i`, `row:i`, `tree:<id>`, `axis:x`). bbox로 그려지므로 레이아웃이 바뀌어도 따라간다.
- **수식의 부분을 가리키기**: item의 tex 안에서 `\p{이름}{…}`으로 부분을 표시하면 `item:<id>/<이름>`이 지시 대상이 된다. 예: `\p{coef}{4}x^{\p{exp}{3}}` → `circle target:"item:t1/coef"`, `pointer target:"item:t1/exp"`. 생략된 지수 1의 자리는 `^{\p{cexp}{\vphantom{1}}}`(폭 0, 보이지 않음)로 만들어 가리킨다. **비율 좌표로 글자 위치를 어림하지 않는다.**
- 손글씨 `arrow_to`: 좌표 대신 **항상 `{"target":"item:frac","anchor":"top"}`** 형태. 끝점은 대상 bbox 가장자리 바깥(anchor `top/bottom/left/right`, 기본 `edge`=메모에서 가장 가까운 변). 분수의 분자·분모는 `item:frac` + top/bottom, 식 오른쪽에 붙는 판정(참/거짓)은 `anchor:"right"`.
- **식 안의 항끼리 잇는 화살표**(분배법칙 A → AB, A → AC 등)는 `"bend":"up"`으로 식 위를 지나는 곡선으로. 여러 개면 `height`를 다르게(가까운 것 34, 먼 것 62) 줘서 서로 겹치지 않게. 직선 화살표는 식을 가로지르므로 같은 줄 항끼리는 쓰지 않는다.
- **예시·계산 필기는 그 설명이 끝나면 지운다**: 한 문장 안에서 쓰고 끝나는 예시(대입, 3²=9 같은 확인, 역수 계산)는 `"until":"sentence"`. 장면 끝까지 남기는 것은 정의 요약·다른 강 예고(→ n강)처럼 다시 볼 필요가 있는 것만.
- 손글씨는 기울이지 않는다(기본 회전 0°). `rotate`는 쓰지 않는다.
- **대입·검산 장면은 원래 식을 칠판에 다시 적는다**: "원래 식에 넣으면"이라고 말할 때 화면에 원래 식이 없으면 학습자가 떠올리지 못한다. 원래 식 → 좌변 대입 → 우변 대입을 말에 맞춰 한 줄씩 적고(`until:"sentence"`), 장면에 원래 식이 이미 보이면 그것을 가리킨다.
- 손글씨 줄바꿈은 `\n`으로 직접. 한 줄 18자까지는 자동 줄바꿈 없이 한 줄로 쓰인다(최대 폭 440px).
- `region`(수직선 전용): `{"type":"region","id":"sol","ranges":[{"from":"-inf","to":-7}],"level":1,"color":"accent","label":"x \\le -7","at":"@…","ttl_ms":0}`. 범위마다 `open:"from"|"to"|"both"`로 빈 원, 생략이면 채운 원, `"inf"`/`"-inf"`는 화살촉. **한 조건 = 한 region = 한 level**(여러 범위도 같은 높이), 조건이 다르면 level·색을 다르게. 연립부등식은 `intersect_with:"r1"`로 공통 구간 띠. `region:sol`·`region:sol/0`은 지시 대상. 경계 포함을 말할 땐 region 전체 대신 그 점(`point:i`)을 circle.
- 수직선에서 눈금과 같은 값의 점(−7 위의 −7)은 `label`을 생략한다 — 눈금이 이미 읽어 준다. 점 라벨은 region 선·마커를 피해 자동 배치되지만, 중복 라벨은 처음부터 두지 않는다.
- 수직선 bracket 라벨은 `label_pos`로 위/아래 선택, 눈금 숫자와 겹치지 않게. 점 라벨은 자동 회피(반대편 → 스택 → 인출선)하므로 `label:"auto"`면 충분.
- `headline.accent_bar:true`: 장면 제목 앞 세로 악센트 바. 뿌리깊은수학은 전 장면 켠다.

## 4. TTS·자막

- 식은 붙여 읽기("에이엑스제곱플러스비엑스"), 분수 "이분의일", 거듭제곱 "에이의세제곱". 단 **숫자끼리의 덧셈은 "삼 더하기 오"**처럼 띄어 읽는다("삼플러스오"는 뭉개짐). 사이시옷이 끼어드는 복합어는 띄어 쓴다: "지수 법칙"(지숫법칙 방지), "분배 법칙". **기호가 길게 이어지면 띄어 읽는다**: "플러스마이너스 루트 에이"("플러스마이너스루트에이"는 "루트 에"로 뭉개짐). 한 단어가 6음절을 넘으면 의미 단위로 띄운다. **읽으면 구별이 안 되는 표현은 고친다**(예: 1/(−3)과 −1/3 → "분모가 마이너스삼인 분수"로 풀어 말함).
- **강조 지시어는 쓰지 않는다**(대표 지시 2026-11-05): `[slight emphasis]`, `[emphasizing]`, `[slowly, emphasizing]`처럼 강세를 요구하는 태그는 음성이 과장되게 튀어서 금지. 중요한 문장은 쉼표·`[short pause]`로 호흡을 주거나 문장을 짧게 끊어 전달한다. 허용 태그: `[warm, steady lecture tone]`(도입), `[short pause]`, `[slowly]`, `[normal pace]`, `[thinking aloud]`, `[concluding, relaxed]`(맺음).
- 앵커 `@…`는 tts 부분 문자열, 지시어(`[short pause]`)는 앵커에 넣지 않는다.
- 자막 42자, 의미 단위. 억지로 끊길 곳은 `text`에 `⏎`. `--captions`로 확인.

## 5. 검수 체크리스트 (장면당 2장)

3. 지시 타이밍: 밑줄·동그라미가 말과 같은 요소를 가리키는가. ttl 때문에 너무 빨리 사라지지 않는가. **언급됐는데 지시가 없는 요소가 없는가**(`node scratchpad/mention-gaps.mjs`로 1차 점검, 최종은 문장별 읽기).

5. 참조: "n강" 번호와 실제 레슨 내용 일치.
7. §9 대표 반복 지적 체크리스트 전 항목 대조, lesson-check STYLE 0건.

## 9. 대표 반복 지적 체크리스트 (제작·개정 전 반드시 대조)

대표가 한 번이라도 지적한 사항은 모두 여기에 모은다. 새 지적을 받으면 **고치기 전에 이 목록에 먼저 한 줄 추가**하고, 자동 검사가 가능하면 `lib/learn/lessons/style-lint.ts`에 규칙을 추가한다(`lesson-check`가 `STYLE`로 출력). 표의 "자동"이 ✓인 항목은 STYLE 경고 0건이 통과 기준.
