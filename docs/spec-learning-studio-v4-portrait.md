# 러닝 스튜디오 LS4-13 — 모바일(세로) 지시·필기 시스템

- 기준: main `6af5d33` 이후. 브랜치 `feat/learning-studio-portrait`.
- 배경(대표 지시 2026-11-05, 참고 `docs/ref/portrait-reference.png` — iPhone 390px, rm-06 s1): 모바일에서 (1) 칠판 전체를 축소해 식이 12px 안팎으로 작아지고, (2) 손글씨 화살표가 대상(A, B)이 아니라 화면 좌상단을 가리키며, (3) 16:9 비율 좌표로 둔 메모가 세로 화면에서 엉뚱한 자리에 놓인다. 데스크톱 레이아웃을 축소하는 방식으로는 해결이 안 되므로 **세로 화면 전용 배치 규칙**을 둔다. 레슨 JSON은 하나로 유지하고(모바일용 별도 저작 없음), 세로에서는 엔진이 다시 배치한다.
- DB·콘텐츠 JSON·음성·push·배포 금지.

## 0. 먼저 고칠 버그 — 축소 상태에서 대상 좌표 불일치

- 참고 이미지에서 `arrow_to:{target:"item:a"}`의 끝점이 A가 아니라 좌상단 먼 곳으로 간다. StageFit(`transform: scale`) 아래에서 `getBoundingClientRect` 기반 대상 측정과 오버레이 SVG `viewBox` 좌표계가 서로 다른 배율로 계산되는 것으로 보인다. 어떤 배율·레이아웃에서도 대상 bbox가 오버레이 좌표와 일치하도록 측정 경로를 하나로 통일하고, 축소 0.3·0.5·1.0에서 오차 1px 미만을 테스트한다. 이 수정만으로도 현재 모바일 화면의 화살표 방향 문제는 사라져야 한다.

## 1. 세로 모드 판정과 글자 크기

- 무대 폭 < 640px이면 `data-layout="portrait"`. 가로(데스크톱)는 지금 그대로.
- 세로에서는 **칠판을 축소하지 않는다.** items·steps·table·chain·callout·손글씨는 실제 px 크기로 렌더: xl 30px, lg 24px, md 18px, sm 15px, 손글씨 20px, 눈금 14px, 라벨 16px(CSS 변수 `--studio-type-*`의 portrait 값).
- 무대는 세로로 길어질 수 있다(내용 높이만큼, 최대 화면 높이의 70%; 넘치면 무대 안 세로 스크롤). 자막·재생 도구는 지금처럼 아래 고정.

## 2. 세로 재배치(reflow) 규칙 — 저자가 쓴 비율 좌표를 쓰지 않는다

| 요소 | 세로 배치 |
|---|---|
| board items `group:"expr"` | 폭에 맞춰 **항 단위로 줄바꿈**(연산자 포함 항이 한 단위), 가운데 정렬, 줄 간격 0.4em. 그룹은 무대 맨 위 |
| board items (그룹 밖) | 비율 좌표 무시. JSON 순서대로 세로로 쌓음(`kind:"note"`는 폭 100%, 그 외 가운데). `order` 필드(선택)로 순서 조정 |
| steps / table / chain / tree | 폭 100%, 표는 열이 3개 이상이면 **행을 카드로 바꿔** 세로 나열(첫 열이 카드 제목) |
| graph / slider | 폭 100%, 비율 유지(수직선은 높이 160px). 눈금·점 라벨은 LS4-9 회피. 손글씨는 아래 3절 |
| figure | 폭 100%, 이미지 비율 유지. items·지시는 이미지 박스 기준 비율 좌표 그대로(이건 이미지에 묶인 것이므로 유지) |

## 3. 지시·필기의 세로 배치 — 대상 기준(target-relative)

- circle·underline·strike·pointer·tint·flash: 대상 bbox 기준이므로 변경 없음(0절 버그만 고치면 됨).
- **callout**: 세로에서는 `position`을 무시하고 대상 **바로 아래**(anchor bottom) 또는 위(anchor top)에 가운데 정렬로 붙인다(`drop` 16px). 같은 대상 아래에 여러 주석이 오면 세로로 쌓음. 주석이 폭을 넘으면 줄바꿈.
- **handwrite**: `arrow_to.target`이 있으면 세로에서는 `position`을 무시하고 대상 가까이에 붙인다 — `anchor`가 bottom/top이면 그 아래/위 12px, left/right면 그 옆, 없으면(`edge`) 아래. 화살표는 6~12px 짧은 선으로 줄이거나 대상에 닿아 있으면 생략. `arrow_to`가 좌표이거나 없으면(순수 메모) 무대 아래 **메모 영역**에 등장 순서대로 쌓는다(손글씨 폰트 유지, 폭 100%).
- **region·bracket**: 수직선에 묶여 있으므로 그대로, level 높이는 20px로 축소.
- 데스크톱에서도 쓸 수 있는 새 position 형식(선택): `"position":{"near":"item:a","side":"below","gap":12}`. 비율 좌표 대신 대상 기준 배치. lesson-check는 둘 다 허용. 매뉴얼은 앞으로 **near 형식을 기본**으로 권장(세로·가로 모두 같은 규칙으로 놓이므로).

## 4. 지시 선 굵기·크기

- 세로에서 분필 선·원·빗금·화살촉은 무대 배율과 무관하게 **px 고정**(선 2px, circle 여백 4px, 빗금 연장 3px). 지금처럼 viewBox 배율에 따라 가늘어지지 않게.
