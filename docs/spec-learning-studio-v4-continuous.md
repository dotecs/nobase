# 러닝 스튜디오 LS4-14 — 한 강 = 하나의 연속 콘텐츠, 목차는 상단 제목 아래로

- 기준: main `dc2954d` 이후. 브랜치 `feat/learning-studio-continuous`.
- 배경(대표 지시 2026-11-06): 장면(scene)은 제작·관리용 단위로만 남기고, 학습자에게는 장면들을 이어 붙인 **하나의 강**으로 보여 준다. "강의 구성" 목록은 aside에서 빼서 main 상단 제목(topTitle) 아래의 **현재 위치 제목 + 펼치는 목차**로 옮긴다. aside는 **전체 교육과정 탐색**에 집중한다.
- 레슨 JSON·DB·음성 스키마는 바꾸지 않는다(장면 구조 그대로). 바뀌는 것은 플레이어·셸·사이드바뿐. DB·콘텐츠·음성·push·배포 금지.

## 1. 강 단위 타임라인

- 강 전체 시간 `T = Σ 장면 길이`(장면 길이 = 지금 장면 플레이어가 쓰는 값: 문장 음성 길이 합 + 기존 간격). 함수 `lessonClock(lesson, durations)` → `{total, sceneStarts[], toScene(t) → {index, local}, toLesson(index, local) → t}`.
- 재생 막대는 **하나**: 0 ~ T. 드래그·클릭 탐색은 `toScene`으로 장면을 바꾸고 그 장면 안 시간으로 seek. 장면 경계에 작은 **챕터 눈금**(호버 시 장면 제목 툴팁).
- 장면 끝에 도달하면 **자동으로 다음 장면 이어 재생**(자동 넘김 설정과 무관하게, 강 안에서는 항상 연속). "자동 넘김" 설정은 이제 **강 → 다음 강** 이동에만 적용(완료 모달 후 다음 강 자동 시작). 설정 이름을 "다음 강 자동 재생"으로 바꾼다.
- 시간 표시는 강 전체 기준 `03:12 / 07:45`. "03 / 06", "이전 내용", "다음 내용" 버튼은 학습자 화면에서 제거(관리자 모드에서는 유지).
- 이어 보기: 마지막 위치를 `lesson_id → t`로 저장(현재 장면 저장 방식을 강 시간으로 대체). URL 해시 `#s3`은 계속 지원 — 해당 장면 시작으로 seek.
- 되감기 정확성: 장면을 거꾸로 넘어가면 그 장면의 `stageStateAt(local)`로 즉시 복원(지금 장면 내 되감기와 같은 규칙).

## 2. 멈춤 지점

- `quiz` 장면, `slider` 장면처럼 학습자 조작이 필요한 장면은 그 장면 **마지막 문장이 끝나면 자동 일시정지**. 정답 제출 또는 "계속" 버튼으로 이어서 재생.
- 장면 전환: 칠판이 통째로 바뀌므로 240ms 크로스페이드(이전 장면 내용 페이드아웃 → 새 무대 페이드인). 전환 중 지시 액션은 그리지 않는다.

## 3. 상단 목차 (main topTitle 아래)

- 위치: 상단 바의 강 제목(eyebrow + h1) **바로 아래 한 줄**: `▸ 02 등식의 성질` — 현재 장면 번호와 장면 제목(`scene.title`, 없으면 headline.title). 장면이 바뀌면 이 줄이 바뀐다(페이드).
- 클릭(또는 ▸)하면 **목차 패널이 아래로 펼쳐짐**: 장면 목록(번호·제목·한 줄 부제), 현재 장면 강조, 완료된 장면은 체크, 각 항목 클릭 시 그 장면 시작으로 seek하고 패널 닫힘. Esc·바깥 클릭으로 닫힘. 패널은 칠판 위에 겹쳐 뜨는 오버레이(무대 레이아웃을 밀지 않는다), 최대 높이 60vh 스크롤.
- 키보드: 목차 버튼 `aria-expanded`, 목록은 `role="list"`, 항목 `aria-current`.
- 세로(모바일): 같은 줄을 상단 바 아래에 두고, 펼치면 바텀시트로.
- 집중 모드: 현재 장면 제목 줄은 좌상단 겹침 제목 아래 작게 유지, 목차 펼치기 가능.

## 4. aside = 전체 교육과정 탐색

- `CourseSidebar`에서 "강의 구성"(장면 목록) 섹션 제거.
- 남기는 것·강화: 현재 강 카드(제목·학습 목표·**강 전체 진행률** — 장면 수가 아니라 시간 비율), 전체 교육과정 트리(단원 → 강, 완료 체크, 현재 강 강조, 준비 중 강 비활성), 단원 접기/펼치기 기억, 현재 강이 있는 단원 자동 펼침, 목록 상단에 "이어서 학습" 바로가기(마지막으로 본 강·위치).

## 5. 관리자 모드

- 관리자 모드에서는 장면 단위 도구를 유지: 장면 ID 배지(`rm-02#s1`), 장면 이전/다음 버튼, 장면별 재생 막대(토글). 강 단위/장면 단위 막대를 전환하는 작은 스위치.

## 6. 검사·테스트·보고

- 테스트: `lessonClock` 경계(0, 장면 경계 ±1ms, T), 장면 넘는 seek 후 상태 복원, 자동 이어 재생, 퀴즈·슬라이더 자동 정지와 재개, 목차 열기/닫기/이동/키보드, 이어 보기 저장·복원, 해시 진입, 관리자 모드 장면 도구.
